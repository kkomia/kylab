- 日期：2026-09-30

  - 用户指令：**chat 前端全部重写、全面对标 Kimi、旧架子积重难返；前端架构师亲笔，后端才派工。**

## 1. 三条抱怨 → 三个设计答案

| 抱怨 | 病根（审计证据） | 对策（本文 §4/§5） |
| --- | --- | --- |
| 输出混乱 | 过程面板默认展开且压在正文上方（§5.3-1）；组行零信息（§5.3-2）；running/done 无差别（§5.3-4） | **工具链块**：一条缩进轴 + 默认收起 + 每行有状态与结论（§4） |
| 工具/思考混进正文 | `<tool_call>` 兜底分支吞掉整条 Markdown（§6.1-7）；思考与正文没有分色 | **正文只许是正文**：标记在模型层剥离；思考进工具链块的灰字区（B3+60% 黑），正文 B1+90% 黑（§5.1/§5.4） |
| 突然出现的块 | 审批条/命令回话/菜单/交付物全部零进出场（§4.2-19/20/21）；滚动全是瞬时（§4.4） | **blur 即转场**：统一入场 `blur(5px)→0 + translateY(8px→0)`；折叠走 grid-rows 编排；回到最新平滑滚动（§5.6） |

## 2. 范围：什么死、什么留

**死（重写）**：`features/chat/ui/` 整层（ChatThread / MessageView / TracePanel / TraceStepRow / Composer / ComposerControls / ApprovalBar / Deliverables / SourceCard / WebSiteList / StepResult / Fold / Welcome / Sheets / chat.css / traceStyles / stepIcons / siteLogos / sourceCardStore）。

**留（不动语义，只做外科手术）**：
- `model/`（liveTurn 常驻流与重连、turns 回合派生、pacer 节拍器、transcript、webSites、sourceCitations、resultDisplay）——协议与派生层被 25 个测试文件钉住，审计结论是它「站得住」；
- `runtime/ChatProvider` 的状态与动作（发送/重试/审批接线）——视新 UI 树的 props 需要**收窄与重排**，不改协议；
- `api/chat.ts` SSE 客户端 —— 只修审计 §6.1-2（未知事件落 error 分支）。

**为什么不是连模型层一起烧掉**：重写它买不到任何观感，只买回风险。用户骂的"架子"是看得见的那层。

## 3. 设计令牌：Kimi 官方值落地方式

**全局 `tokens.css` 不动**（笔记/知识库/设置在吃它）。chat 域局部定义一套 `--ch-*` 变量，值**逐字抄** Kimi 源码：

| Kimi 源码 token | 值（浅/深） | 落为 |
| --- | --- | --- |
| `--Labels-Primary` | `#000000e6` / `#ffffffd6` | `--ch-label-1`（正文） |
| `--Labels-Secondary` | `#0009` / `#ffffff8f` | `--ch-label-2`（工具链标题、思考、结果标题） |
| `--Labels-Tertiary` | `#00000073` / `#ffffff6b` | `--ch-label-3`（域名、chevron、辅助） |
| `--Labels-Quaternary` | `#0000004d` | `--ch-label-4` |
| `--Bg-Primary/Secondary` | `#fff` `#f5f5f5` / `#121212` `#1f1f1f` | `--ch-bg-1/2` |
| `--Separators-S1` | `#00000021` / `#ffffff1f` | `--ch-hairline`（0.5px 描边） |
| `--Colors-KMBlue` | `#1783ff` | `--ch-accent` |
| 字号 | T2 16/24 · B2 14/20 · C1 12/18 · 正文 16/26 · 思考 14/22 | `--ch-fs-*` |
| 缓动 | out `cubic-bezier(.23,1,.32,1)` / close `cubic-bezier(.55,0,.18,1)` | `--ch-ease-out/close` |

字号仍乘全局 `--font-scale`（用户的字号设置不能失效）；深色跟随现有 `data-theme` 机制反相。

## 4. 工具链块（TracePanel 的替代物，本设计的核心）

结构（对标设计文档 §1.1 骨架）：

```
┌ [头像] 工具链标题（图标 + 一句话任务摘要）              ⌄ ┐  ← 整行 button，24px 高
│        │                                                │
│        ├ • 子目标行（bullet）                            │  ← body：左侧一条竖向引导线，
│        ├ 🔍 搜索网页（38 个结果）                     ⌄  │     所有子项对齐同一根轴
│        │    └ 结果列表（favicon 16 圆 + 标题 + 域名）    │     （max-h 256 + 底部渐隐）
│        ├ • 思考已完成（N 字）                         ⌄  │
│        │    └ 思考正文（B3 灰字，max-h 268 + 边缘渐隐）  │
├────────┴────────────────────────────────────────────────┤
│ 正式回复（B1 16/26，Labels-Primary；表格/文件卡片）        │
└──────────────────────────────────────────────────────────┘
```

行为默认值（与旧面板一刀两断）：

| 层级 | 默认 | 说明 |
| --- | --- | --- |
| 工具链块整体 | **流式中展开、收尾后收起**成一行摘要 | 旧版"默认展开压正文"是用户第一条抱怨；收起后摘要行 = 图标 + 「用了 N 步 · M 个来源」+ chevron |
| 搜索行 | 收起（标结果数）；展开出列表 | 行高 32、favicon 16 圆、标题 B2 二级色、域名三级色右对齐 |
| 思考行 | 收起（标字数）；展开出灰字正文 | 流式中的思考**只在块内**流动，不进正文 |
| 单步状态 | running = shimmer 文案；done = 正常色 | 旧版两者零差别（审计 §5.3-4） |
| 被拦下/待确认 | **始终展开且前置** | 保留旧版这一条的语义（那是审批的命根子） |
| 分组 | 保留 `turns.ts` 的同工具合并（12 行→4 行那套），但组行带**耗时与结论摘要** | 旧组行零信息（§5.3-2） |

数据从 `turns.ts` 的 TraceStep 派生模型取（保留），视图层全换。记忆类步骤**不再隐藏**（审计 §6.1-8：隐藏连带推理一起消失）——归为「记忆」行，默认收在块内。

## 5. 逐域规格

### 5.1 正文管线（`model/markdown.tsx` 保留，动两点）
- **标记剥离上移**：`<tool_call>` / 思考残片在 `turns.ts` 派生正文时剥离（正则已有，把"剥离"从渲染分支挪到派生层）；`MessageView` 的「工具标记兜底分支」**删除**——正文永远走完整 Markdown。
- 徽标、代码块两段式、表格头卡片**形态保留**，视觉换成 Kimi 卡片：灰头（`--ch-bg-2`）+ 0.5px hairline + 12px 圆角（设计文档 §9）。

### 5.2 消息列
- 助手轮：**40px 头像沟槽取消**，改 Kimi 式 56px 头像位（视觉宽 44，源码 `margin-right:-12px`）；头像 = 蓝圆底 + 双白胶囊竖条，生成中双柱 `translateY ±2px` 反相 800ms + 呼吸 1600ms（Rive 的平替，设计文档 §4 建议值）。
- 用户气泡：`--ch-bg-2` + 12px 圆角 + 10/12 内边距（设计文档 §9 实测值），右对齐不变。
- 轮间距：助手段容器 `padding: 16px 0 12px 16px`（源码值）。

### 5.3 输入卡片（Composer）
- 壳形保留（圆角卡片 + 控制行），**值换 Kimi**：卡片头/附件片/控制行间距落 4 的倍数表（§10）；发送键 32×32 不变。
- 「+」菜单 / 权限 / 知识库 / 模型四颗触发器**补进出场**（fade+slide 8px，150/200ms 编排）——旧版四颗菜单全是瞬时（审计 §4.2-21）。
- 知识库开关滑块**真的要滑**（修审计 §6.1-5：transition 覆盖链）。

### 5.4 思考与草稿分色
- 思考 = B3（14/22）+ `--ch-label-2`；正文 = B1（16/26）+ `--ch-label-1`。一眼可辨（设计文档 §3）。

### 5.5 引用与来源
- 行内徽标保留短名形态；来源列表并入工具链块的搜索行（不再正文上方另起一摊）。点徽标 → 块内对应来源行高亮 + 平滑滚动（scrollIntoView smooth；旧版那条 1400ms 闪一下保留但换 token）。

### 5.6 动效总表（全域统一，消灭"突然出现"）

| 场景 | 规格（全部抄设计文档 §12） |
| --- | --- |
| 任何新块入场（审批条/命令回话/交付物/菜单） | `kimi-in`：blur(5px)→0 + translateY(8→0)，300ms `--ch-ease-out` |
| 折叠/展开 | grid-rows 0fr↔1fr；收起 250ms out（先消失再收拢）、展开 380ms close（内容延迟 300ms 再淡入） |
| 滚动容器边缘 | 35px 五段阶梯渐隐（sticky 层 + JS 按滚动位置切 opacity） |
| 思考中 | shimmer（background-position 扫光） |
| 回到最新 | smooth 滚动 400ms（旧版是跳） |
| **reduced-motion** | pacer 逐字流 + 全部过渡/关键帧**一刀切降级**（对话域目前零覆盖，审计 §4.6） |

### 5.7 空态 / 骨架 / 失败 / 审批
- Welcome 保留内容结构，视觉按 token 重排；骨架屏三处行为归一（静止灰条 → 统一 `kimi-shimmer` 骨架）。
- 失败轮 / 降级轮 / 审批条的**文案与语义不动**（审计 §3.6/§3.7 钉死的部分），只换入场与边框规格。

## 6. 测试策略

- **模型层既有 25 个测试文件不动**（它们钉的是派生与协议）。
- UI 层测试**随组件重写**：trace 系 9 个文件（chat-trace-*）与 chat-ui 的过程面板段按新结构重写断言；视觉默认值（折叠态、分色、动效类名）用 DOM 断言钉。
- 新组件每个配 vitest：默认折叠态、展开交互、running/done 差异、渐隐出现条件、reduced-motion 降级。
- 门禁照旧：typecheck / eslint / prettier / vitest 全量 / `check_layering.py` 文案门禁（U1 等）。

## 7. 分期（每期独立可验收）

1. **P1 地基与工具链块**：`--ch-*` token、动效原语（`KimiFold` grid-rows 折叠、`EdgeFade`、`AvatarPulse`、shimmer 工具类）+ 工具链块全状态 + 配套测试。✅ 目标：长任务不再把正文顶出首屏。
2. **P2 正文与消息列**：标记剥离上移、头像、消息列排版、来源并入、交付物卡片、引用联动。
3. **P3 输入卡片与空态**：Composer 换肤 + 菜单进出场 + 开关滑动 + Welcome/骨架归一。
4. **P4 流式与动效收尾**：LiveLine 替代物、审批条入场、滚动 smooth、reduced-motion 全量、审计 §6 八条真缺陷清零（逐条核对）。
5. **P5 门禁与真链路**：全量 vitest/typecheck、桌面壳里跑真实会话验收（工具密集 + 长回答 + 审批三类）。

## 8. 明确不做

- 不动 SSE 协议、不动 assistant-ui runtime 适配层（除非 P4 滚动需要）、不动后端（后端需求另派 DeepSeek，如思考/工具标记的服务端剥离兜底）。
- 不动其它页面；不做视觉回归基建（本期没有 playwright，靠 DOM 断言 + 真链路走查）。
- Rive 素材不引入（双柱 CSS 平替）。

## 9. 风险

- **测试重写量**：trace 系 ~9 文件断言全换，是 P1/P2 最大的工作量 → 每期门禁先跑相关文件再全量。
- **assistant-ui 视口**：平滑滚动与其 instant 行为冲突时，允许在 P4 把视口换成自有滚动容器（ runtime 不动）。
- **`--font-scale` 兼容**：Kimi 字号值须乘 scale，验收时调字号走一遍。
