## 0. 目标与验收

**目标**：把评审报告里**经核实的** P0/P1 清掉，P2 收口；界面形态向三家公开面上能看到的成熟做法靠拢
（空态输入卡、工具在左下发送在右下、侧栏主操作做成卡片、输入区收纳"这次问的是哪份知识"），
但**不照搬**营销落地页那套极简。

**验收（每条都要有）**：

1. **同位置前后对照图**：用 `.shots/capture-round.cjs` 那套脚本重拍同编号的图，人工比对；
2. **门禁**：`sh scripts/check-frontend.sh`（661 条用例 + lint + tsc + 构建）与 `sh scripts/lint.sh` 全绿；
3. **文案纪律**：不新增解释性小字（`check_layering` 的 U1 会拦）；界面文案改动要么删、要么进 ⓘ；
4. **不回归既定选择**：思考块默认展开（v0.25）、正文 66ch 列宽、克制动效、无 emoji —— 都不动。

**硬约束**：只动前端；不引新依赖（沿用既有组件与令牌）；后端协议不变。

**两条只有后端能解（已查清到行，前端不硬造）**：
- **检索没有相关度下限**：`score` 是 RRF 名次分 `1/(60+rank)`（`retrieval/fusion.py:15`），**与相关度无关**；

- **判据一**：文件里有 `@layer <名字> {` 块时，必须先写一句显式层序声明
  `@layer theme, base, components, utilities;`（层的先后由名字**首次出现的位置**决定，不声明就由加载顺序决定）；
- **判据二**：`@layer` 块**之外**不允许普通样式规则（顶层 `@media` 里的也算层外）。
  `@keyframes` / `@font-face` / `@theme` 这类不参与级联竞争的 at-rule 跳过；
- **两类例外**：规则上方写 `/* @unlayered: 原因 */`（真只能靠层外身份的，如上面那 4 条）、
  以及 `CSS_UNLAYERED_FILES` 里的**文件级**豁免（四个基座文件，逐条写理由；默认空着）；
- **反向验证**（`.shots/batch5-reverse-verify.py`，每次改完核 hash 还原一致）：整份去掉分层外壳 → 117 条违规；
  只删层序声明 → 1 条；只删例外标记 → 1 条；还原后全绿。**一条永远绿的检查等于没有检查**。
