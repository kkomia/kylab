# 前端设计规范 · v0.3

> 适用：知识库产品 Web 控制台（含检索调试台）
> 日期：2026-09-10
> 状态：基线（当前有效版本，随界面开发迭代）
> 变更摘要：在 v0.1 基础上新增原则 6「形态随数据量」与 §5.1 形态选择规则——容器型对象（知识库、数据源）条目少时用卡片网格，条目型对象（文档、任务、命中块）条目多时用列表，默认阈值 12 条；据此更新 §6 页面映射的形态描述与 §7 的卡片/列表行细则。v0.1 的原有条文一字未改（§1 原则 1–5、§2 全部 Token 与其用途、§5 布局骨架、§8 禁忌五条逐字沿用）。v0.2 为中间稿且被就地修改过，已被本版取代。
> 基线风格：Notion 风（参考 vibe-hub.org/style-notion）
> 项目硬性约束：**全程禁止 emoji；图标一律内联 SVG；黑白双主题（参考 Kimi 明暗主题）**

---

## 1. 设计原则

1. **内容即界面**：去掉多余的壳与装饰，知识库内容本身就是界面。控制台不是仪表盘，不堆卡片和图表。
2. **以灰阶建立文字层级**：标题、正文、注释用明度分级；关键状态（失败/警告/成功）才使用有含义的颜色。
3. **细分割线配合留白分区**：1px 细线分段，文档像一张稿纸放在灰桌上，边界浅但清楚；复杂表格与输入控件可用更明确的边框。
4. **次要操作按需出现**：hover / 键盘聚焦时显示；触屏与键盘用户必须能找到同一入口（不只依赖 hover，提供可见的 `⋯` 按钮或焦点态）。
5. **全程禁止 emoji**（对 Notion 官方风格的覆盖）：界面、图标、空状态插画、状态标记、通知文案一律不使用 emoji。Notion 风中"emoji 作页面图标"的做法在本项目一律以内联 SVG 替代。
6. **形态随数据量**：同一种对象在不同规模下换形态，不要一套容器用到底——条目少（容器型对象）用**卡片网格**，条目多（条目型对象）用**列表**。判定条件与做法见 §5.1。

## 2. 主题系统（黑白双主题，参考 Kimi）

两种主题均为**近白 / 近黑的克制灰阶**，不做高饱和品牌色铺底。主题跟随系统，可手动切换，切换按钮放侧栏底部。

### 2.1 浅色主题（Light）

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg-canvas` | `#F7F7F5` | 页面底层画布（暖灰桌） |
| `--bg-surface` | `#FFFFFF` | 内容区 / 卡片 / 弹层 |
| `--bg-hover` | `#F1F1EF` | 行 hover、菜单项 hover |
| `--bg-active` | `#E9E9E7` | 选中项（侧栏当前库等） |
| `--text-primary` | `#37352F` | 标题、正文 |
| `--text-secondary` | `#73726E` | 注释、元信息 |
| `--text-tertiary` | `#A3A29E` | 占位、禁用 |
| `--border` | `#E4E4E0` | 1px 细分割线 |
| `--border-strong` | `#D0D0CC` | 表格、输入框边框 |

### 2.2 深色主题（Dark，参考 Kimi 深色）

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg-canvas` | `#1A1A1A` | 页面底层画布 |
| `--bg-surface` | `#232323` | 内容区 / 卡片 / 弹层 |
| `--bg-hover` | `#2C2C2C` | 行 hover |
| `--bg-active` | `#33332E` | 选中项 |
| `--text-primary` | `#E8E8E6` | 标题、正文 |
| `--text-secondary` | `#9B9B97` | 注释、元信息 |
| `--text-tertiary` | `#6B6B67` | 占位、禁用 |
| `--border` | `#333330` | 1px 细分割线 |
| `--border-strong` | `#45453F` | 表格、输入框边框 |

### 2.3 语义色（双主题共用，深浅主题下微调明度）

| 语义 | Light | Dark | 用途 |
|------|-------|------|------|
| 成功 / 已索引 | `#448361` | `#529E72` | 任务完成、文档 indexed |
| 警告 / 卡住 | `#D9730D` | `#E8873A` | 任务标黄、额度将尽 |
| 失败 / 错误 | `#D44C47` | `#E16259` | 解析失败、token 过期 |
| 信息 / 处理中 | `#337EA9` | `#529CCA` | 任务进行中、链接 |

> 语义色只用于**状态传达**，不用于装饰。正文、标题、背景保持灰阶。
> 实测提示（2026-09-10）：浅色主题下 warning `3.28:1`、danger `4.26:1`、info `4.47:1` 略低于 AA 正文标准，
> 因此这三个颜色**不得单独承载正文级信息**，必须与图标/文字标签双编码（§8 已有要求）。

### 2.4 实现约定

- 主题用 CSS 变量 + `data-theme="light|dark"` 切换；图片/SVG 图标全部走 `currentColor`，随主题自动变色；
- 所有文字/背景组合对比度 ≥ WCAG AA（正文 4.5:1，大字 3:1）；
- 禁止纯黑 `#000` 与纯白文字直撞（Kimi 式柔化处理：深色文字用 `#E8E8E6` 而非 `#FFF`）。

## 3. 图标系统（全 SVG，零 emoji）

| 规则 | 说明 |
|------|------|
| 来源 | 统一内联 SVG（不引 iconfont、不用图片图标、不用 emoji） |
| 基准库 | Lucide / Heroicons（MIT 协议），统一一套不混用 |
| 线宽 | 1.5px 描边风格，与 Notion 风的细线气质一致 |
| 尺寸 | 16 / 20 / 24 三档；侧栏菜单 16，按钮内 16，空状态插画可用 48 线稿 |
| 颜色 | 一律 `stroke="currentColor"` / `fill="currentColor"`，不硬编码色值 |
| 文件类型图标 | 自制极简 SVG 线稿（PDF/DOC/表格/MD/图片/RSS），形状区分 + 文字角标 |
| 状态指示 | 优先"SVG 图标 + 文字"，如任务状态用 旋转 loader SVG / 对勾 / 叹号 + 文字，不用色点单独表意 |

**Emoji 禁令的执行范围**：UI 组件、空状态、错误提示、通知、文档内容渲染层的默认装饰。用户自己文档内容里的 emoji 属于数据，照常渲染。

## 4. 字体与排版

| 项 | 规范 |
|----|------|
| 中文 | 系统栈：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` |
| 西文/数字 | `"Inter", system-ui`（数字等宽场景用 `tabular-nums`） |
| 代码/路径 | `"JetBrains Mono", "SF Mono", Consolas, monospace` |
| 正文字号 | 14px / 行高 1.7 |
| 标题 | h1 24 / h2 18 / h3 16，字重 600，仅明度分级不加彩色 |
| 注释 | 12–13px，`--text-secondary` |
| 内容区宽度 | 阅读类内容限宽 720px 居中；数据表格/任务列表可全宽 |

## 5. 布局骨架

```
┌──────────────────────────────────────────────────┐
│  侧栏 240px（可收起）        │  内容区                │
│  ─ 产品名（SVG logo）        │  ─ 页标题 + 次要操作(⋯) │
│  ─ 搜索                      │  ─ 1px 分割线           │
│  ─ 知识库列表（树）          │  ─ 内容                 │
│  ─ 数据源 / 任务 / 设置      │                         │
│  ─ 底部：主题切换 / 状态      │                         │
└──────────────────────────────────────────────────┘
```

- 侧栏：`--bg-canvas` 底，选中项 `--bg-active` + 左侧 2px 指示条；hover 出现该行次要操作；
- 内容区：`--bg-surface`，顶部分页标题（大号、灰黑），下方 1px 分割线；
- 整体无卡片堆砌；分区靠留白 + 细线，不靠山影和圆角大卡片。

### 5.1 形态选择：卡片网格 vs 列表

同一种对象在不同规模下换形态，不要一套容器用到底。

| 条件 | 形态 | 典型对象 |
|------|------|----------|
| 条目 ≤ 12，且一屏可看全（无分页需求） | **卡片网格** | 知识库、数据源、项目/集合等**容器型**对象 |
| 条目 > 12，或需要排序 / 筛选 / 批量操作 / 分页 | **列表**（含极简表格） | 文档、chunk 命中、任务、日志等**条目型**对象 |

- **判定依据是"要不要扫描比较"，不是数字本身**：需要在一屏内做"选哪一个"的决策 → 卡片；需要在长列表里"找某一条" → 列表。阈值 12 是默认起点，可按实际布局调整；
- **同一对象随规模切换形态**：知识库从 3 个长到 30 个时，首页由卡片网格改为列表，而不是把卡片挤成越来越窄的格子；
- **空状态与 1–2 条一律用卡片**：避免"只有一行数据的表格"这种空洞形态；
- 卡片网格与列表**可以并存于同一对象**：如知识库首页用卡片、侧栏用树/列表做导航；
- 本节的卡片是**受限形态**而非默认容器：条目超过阈值必须切回列表，卡片本身不得加阴影或大圆角（细则见 §7）。§1 原则 1"不堆卡片"与 §8 的卡片堆砌禁令继续有效，本节的适用上限即为其边界。

## 6. 核心页面映射

| 页面 | Notion 风落点 |
|------|---------------|
| 知识库列表 | **卡片网格**（条目少时，见 §5.1）：每张卡 = 名称 + 条目数/最近更新时间 + hover 出现的 `⋯`；超过阈值改列表。侧栏仍保留页面树做导航，支持右键/键盘菜单 |
| 文件列表 | **列表**（条目多）：文件类型 SVG 图标 + 名称 + 状态（文字+语义色）+ 时间；大文件点击展开**子文件树**（切分块 P1–Pn，缩进一级） |
| 任务中心 | **列表**：文档流式列表而非仪表盘，每行一个任务，进度用文字 + 细进度条（2px），卡住自动标黄/红 |
| 检索调试台 | 双栏：左对话流（稿纸感气泡-less 排版），右侧"命中 chunks"面板——命中数 ≤12 用卡片（1px 边框，显示来源、页码、相似度，图片锚点内联缩略图），超过则切紧凑列表 |
| 文档详情 | Notion 文档页形态：标题 + 元信息行 + Markdown 预览（排版样式见第 4 节），下载按钮两个选项（Markdown / 原文件，默认原文件） |
| 设置 | 分组列表 + 右对齐控件；解析节点、API Key、embedding 配置均为"标签 + 描述灰字 + 控件"三段式 |

## 7. 组件细则

- **按钮**：主按钮 = 灰黑实心（Dark 下近白）；次按钮 = 透明 + 1px 边框；危险按钮 = 语义红文字，hover 浅红底；
- **输入框**：1px `--border-strong`，聚焦时边框加深 + 无外发光；
- **弹层/菜单**：`--bg-surface` + 1px 边框 + 4px 阴影，圆角 6px；
- **圆角**：全局克制，控件 6px，卡片/面板 8px；
- **卡片**（仅用于 §5.1 判定为卡片网格的场景）：`--bg-surface` 底 + 1px `--border` + 8px 圆角，**无阴影**；卡内三段式——标题（16px / 600）、元信息（12–13px `--text-secondary`）、次要操作（`⋯`，hover 或键盘聚焦时出现且触屏可点）；hover 只把边框转 `--border-strong`，**不做位移/缩放/阴影动画**；网格间距 12px，列宽自适应（`minmax(220px, 1fr)`，窄屏单列）；
- **列表行**：行高 40px，行底 1px `--border`，无竖线；hover 整行 `--bg-hover`；行首固定宽度放类型图标（16px），行尾放状态与时间（`--text-secondary`、`tabular-nums`）；列表页首行不加额外分隔线，避免"表格套表格"；
- **空状态**：线稿 SVG（48px）+ 一句灰字 + 一个主操作按钮，不用彩色插画、不用 emoji；
- **加载**：骨架屏用 `--bg-hover` 色块呼吸，或细线 spinner SVG；卡片网格的骨架屏保持与卡片一致的尺寸，避免加载完成时跳版；
- **Toast/通知**：顶部细条，语义色图标 + 文字，3 秒自消；
- **表格**：行高 40px，行底 1px 细线，无竖线；hover 整行 `--bg-hover`。

## 8. 可用性与禁忌

**必须**：
- 所有 hover 才出现的操作，同时提供键盘焦点可见与触屏可点的入口；
- 状态必须"图标/颜色 + 文字"双编码，照顾色弱与截图场景；
- 深浅主题切换无闪烁（CSS 变量一次切换，不做过渡动画 >200ms）；
- 卡片网格在窄屏退化为单列，且卡片内部不出现横向滚动。

**禁止**：
- 任何 emoji（UI 全链路，见第 3 节执行范围）；
- 高饱和品牌色铺底、渐变背景、玻璃拟态；
- 仅 hover 可见的关键操作（触屏无法发现）；
- 图片图标 / iconfont / 外链图标库；
- 大圆角（>8px）、重阴影卡片堆叠的"仪表盘风"。

- 技术栈：Vue 3 + Vite（见架构 v0.2 §2.1）；主题变量落地为 `:root[data-theme]` CSS 自定义属性；

- 本规范约束的页面 = 架构文档 §3.3 检索调试台 + §4 流水线可视 + §12 可观测性界面的视觉落地。
