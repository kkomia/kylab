# React 迁移：逐页对照记录 v0.1

- 日期：2026-09-23
- 方法：两套前端**同时起着**（旧 Vue 5173 / 新 React 5174，都连同一个本地后端与同一份数据），
  浏览器窗口 1440×900，同一条会话 / 同一个库 / 同一屏逐页截图对照。
- 会话来源：两个来源在浏览器里都已有**有效登录会话**（我们只做**只读**浏览：
  不开任何会改数据的按钮；截图与 DOM 探针都是读操作）。
- 结论：**逐页能对上**——正文、引用徽标、交付物卡片、过程面板、表格列、工具栏、页码都对得上；
  三处差异已当场修掉，其余是观感细节（列在下面，需不需要跟旧版逐像素对齐由用户拍）。

## 2. 修掉的三处（都在本轮提交里）

1. **侧栏账号区空白**：`AuthGate` 放行分支原来只检查"有没有令牌"，没有调用 `restoreSession()`
   ——`currentUser` 一直是 null，账号名/角色/头像都不显示，而且令牌过期时不会自动回登录页。
   现在放行前验一次（失败即清令牌并转登录页）。
2. **概览六个大数的网格**：新旧都是"3 列 × 2 行"，新前端写成了 6 列。
3. **勾选框/单选圈的对比度**：`--border`（分隔线色）换成 `--border-strong`。
