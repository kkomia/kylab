# 前端设计规范 v0.13

本文是 v0.12 的**视觉体系修订版**，只覆盖与"美术风格"有关的条款；v0.12 中其余条款（信息架构、文案、交互、组件约定）继续有效。

- **修订范围**：§2 主题与配色、§4 字体排版，以及底下所有与"较浅的灰是否合格""圆角多大""动效多快"有关的取值。
- **取值依据**：`docs/Kimi-设计token对照表.md`（从 Kimi 线上样式表抓取并解析的 372 个自定义属性，含浅/深两套与字号三档的实测值）。
- **决策来源**：产品侧要求"全面对齐 Kimi Work 的美术 UI 风格"，并明确"直接抄设计、精确到具体值、可以修改设计文档"。

---

## 1. 取值的唯一来源改为 Kimi

主题值不再由我们自行推导，**以 Kimi 的 token 为准**：底色暖白 `#fbfaf9`（深色 `#181817`）、文字用 alpha 灰阶（`#000000e6` / `#ffffffd6` 一族）、品牌蓝 `#1783ff`、分割线 `#00000021`。

实现上分两层：主题文件里**先写 Kimi 的同名 token（源）**，再把我们原有的名字（`--bg-canvas`、`--text-primary`…）**别名指过去**。这样换肤只改一处，近百个组件不必逐个改。

**注意**：主题文件的注释里写明了每个值取自 Kimi 的哪一族，改动时请一并更新，不要让注释与值分叉。

## 2. 撤回 v0.12 §2.4 的"所有灰阶必须 4.5:1"硬门槛

原文要求三级灰也必须过 AA。Kimi 的实际取值做不到，也不打算做到：

| | 浅色（底 `#fbfaf9`） | 深色（底 `#181817`） |
| --- | --- | --- |
| Labels-Primary | 16.88:1 | 12.71:1 |
| Labels-Secondary | 5.68:1 | 6.31:1 |
| Labels-Tertiary | **3.35:1** | 4.08:1 |
| Labels-Quaternary | **2.11:1** | 2.34:1 |

**新条款**：照抄 Kimi 的值，`--text-tertiary` 与 `--text-quaternary` **不再受 4.5:1 约束**。作为交换，增加下面这条**用途约束**（约束的是用法，不是色值）：

- 正文、表单标签、表头、按钮文字、列表主字段：只能用 `--text-primary` / `--text-secondary`；
- `--text-tertiary`：只给**可略过的元信息**（计数、时间戳、脚注、二级说明）；
- `--text-quaternary`：只给**禁用态与占位符**，不承载任何信息。

**为什么不是"放宽到 3:1"**：Kimi 的四级灰是 2.11:1，本就低于 3:1；把它限制在"不被读到也没关系"的位置，比统一放宽门槛更安全——门槛一放宽，正文也可能被写成三级灰。

## 3. 语义色：填充与文字分开

Kimi 的 `Colors-*` 是**填充色**（按钮底、气泡底、图标），当文字用不合格：品牌蓝 3.52:1、绿 2.22:1、黄 1.39:1。因此：

- 填充（按钮底、胶囊底、图表、图标）用 `--Colors-*` 原值；
- 文字（链接、彩色数字、状态文字）用同色相的达标档：`--accent-text` `#006eed`、`--status-success` `#0f853a`、`--status-warning` `#a96300`、`--status-danger` `#e90014`（均在 4.5:1 以上）。
- **深色主题不需要这一档**：Kimi 的深色色值本身就在 5.08:1 以上，直接用原值。

这是本次唯一一处"新增 Kimi 没有的 token"，理由与实测值写在 `light.css` 的文件头。

**白字压品牌蓝是 3.67:1**，低于正文门槛。按 Kimi 的做法保留蓝色实心按钮（按钮文字 ≥14px 且字重 500，按大字号标准 3:1 合格），这一条连同实测值记在主题文件里，属于已知取舍。

## 4. 字体与排版

- **字体栈按 Kimi 的顺序**，纯系统字体，不引 webfont 做正文；等宽字体为 **Geist Mono**（本机没有时逐级回退，`--font-mono` 是一条链）。
- **字阶改为 Kimi 的六档**：`ui-T1` 18 / `ui-T2` 16 / `ui-B1` 15 / `ui-B2` 14 / `ui-C1` 12 / `ui-C2` 10（默认档）。
- **页标题从 28px 降到 18px**。这是有意为之：Kimi 的层级不靠大标题，靠留白与密度。此前"页标题是唯一重音"的写法随之作废。
- **行高**：UI 文字用 `--line-ui`（1.47，取自 `ui-B1` 的 22/15）；长篇阅读面（文档正文、Wiki、命中引文）用 `--line-prose`（1.7），不要全局用 1.47 读长文。
- **`--text-c2-size`（10px）只允许用于拉丁字母与数字**（版本号、计数徽标）。中文最小仍用 12px——10px 的中文在常规显示器上无法辨认，这条约束不接受例外。
- 字号的用户可调档（`--font-scale`，设置 → 外观，0.933 / 1 / 1.15）**保持不变**。Kimi 的三档是"换整套值"，我们用乘法近似，少数档位会差 1px，这是已知偏差。

## 5. 圆角、动效与结构常量

- **圆角**：控件 10 / 行 12 / 面板 16 / 浮层 20 / 输入 24 / 图标按钮 20 / 胶囊 999。Kimi 实测只暴露了三个（输入 24、弹层 20、图标按钮 20），其余按同比例推上去。
- **动效统一**：`--transition-ui`（`.15s ease`）。组件里不要再写 `.12s` / `.2s` 这类一次性时长。
- **图标按钮**：高 36px、描边 **0.5px**、圆角 20px、图标不透明度默认 .56 / hover .84 / 禁用 .26。
- **弹层表面**用 `--bg-overlay`（深色是带蓝调的 `#262630`，不是中性灰）。
- `--control-height`（32px）与间距 4px 阶梯**本次不动**：Kimi 的样式表没有暴露按钮与输入框的高度，没有依据就不改，避免把工具栏整体撑高。

## 6. 不变的部分

- **禁止 emoji，图标只用内联 SVG**（`scripts/scan_emoji.py` + eslint 规则）；
- 间距只用 `--space-*` 阶梯，`--space-pair` 仍只允许用于成对文本；
- **不引入 Tailwind**（Kimi 自己也没用；与现有 scoped style + token 体系冲突）；
- 文案条款（v0.12 §8.1，`scripts/audit-copy.py`）不变。

### 一条已澄清的误判（留给后来者）

改版过程中曾记录「切主题时热力图不重新取色」为缺陷，**实测证明这是误判**，已撤回。实际行为是对的：`EChart.vue` 里 `watch(theme, render)` 会在主题变化时重画，`ActivityHeatmap` 传入的 `var(--heat-*)` 由 `resolveColors` 在重画时重新解析。实测（点应用内的「切换为深色」）：`--heat-0` 由 `#eeeff1` → `#232326`，内容区底色由 `#fbfaf9` → `#181817`，色块同步更新。

误判的来源值得记一笔：**用 `document.documentElement.dataset.theme = 'light'` 直接改属性，不会触发 Vue 的响应式**，图表因此保持旧色。以后再手工验证主题相关行为，必须点应用内的开关（`setTheme`），不要直接改 DOM 属性——否则会把"测试手法不对"当成产品缺陷。
