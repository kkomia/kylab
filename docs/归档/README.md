# 归档区

> **这里是被取代、或已经完成的历史材料，只供追溯——不是现行口径。**

接手开发时**不要**从这一区出发；现行的东西在这三处：

| 想看什么 | 去哪个目录 |
| --- | --- |
| 必须遵守的约定（分层 / 命名 / 门禁 / 提交 / 部署） | [`../规范/`](../规范/) |
| 设计基线（架构、工作区、记忆、对话 UI、插件与技能） | [`../设计/`](../设计/) |
| 进度、验收物证、交接说明、计划 | [`../计划与记录/`](../计划与记录/) |

## 归档的纪律

- 移进来用 `git mv`（保留历史），别"删掉再新建"；
- 移进来之后**必须**同时改掉所有指向它的链接（`docs/README.md` 的索引、别的文档里的相对链接）；
- 判断标准只有一条：**它还是不是现行口径**。是，就留在 `规范/` / `设计/` / `计划与记录/`；不是，才进这里。
